# Prompt kit

Use these when you'd rather have an AI assistant (Claude, ChatGPT, etc.) make your Story than edit code yourself.

| File | Use it when |
|------|-------------|
| [`1-my-info-form.md`](1-my-info-form.md) | Fill this in first. Every prompt below uses it. |
| [`2-prompt-fill-config.md`](2-prompt-fill-config.md) | You downloaded this repo and want the AI to write `my-travel.js` for you. |
| [`3-prompt-design-from-scratch.md`](3-prompt-design-from-scratch.md) | You have no code at all and want the AI to design the whole Story. |
| [`4-style-guide.md`](4-style-guide.md) | Colors, fonts and layout rules for each design, so you can match the look or invent your own. |

**Tip:** attach a screenshot of the design you like from `examples/featured/` together with the prompt. Assistants copy a style much more closely when they can see it.
